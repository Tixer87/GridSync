# GridSync Voice Packs

GridSync creates community voice packs for iRaceDeck Race Engineer.

## Purpose

The voice pack project focuses on creating complete, usable race engineer and spotter experiences rather than isolated audio samples.

Packs are designed around the active iRaceDeck callout structure and are tested as working packages before release.

## Current Projects

### Ryan Race Engineer

A serious English race engineer voice intended for regular use.

### Snoop Voice Pack

A stylized English community voice pack with a more relaxed personality.

### Family Guy

A multi voice fun pack built around multiple characters inside one package.

### Pit Wall Legends

A motorsport inspired race engineer project.

## Releases

Voice pack releases are distributed through GitHub Releases and linked through the GridSync website.

Website:

https://gridsync.ch/

## iRaceDeck

The packs are built for iRaceDeck Race Engineer.

The GridSync project is community created and is not the official iRaceDeck project.

## Pit Radio Integration

When a new GitHub Release is published, Pit Radio can automatically create a Discord release broadcast.

This connects the release workflow directly with the GridSync community without requiring a separate hosted bot.
